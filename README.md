# Чистый Борт (PureDetail) — White-Label MVP студии автодетейлинга и химчистки

Готовое к коммерческой перепродаже полнофункциональное white-label веб-приложение для студий автодетейлинга, выездной и стационарной химчистки салона, полировки и нанесения защитных составов.

Приложение спроектировано **без тяжёлых 3D-моделей**: визуализация работает мгновенно на сверхбыстрых векторных SVG-схемах зон автомобиля и легковесном 2D Canvas.

---

## 🌟 Ключевые возможности

### Для клиентов студии:
1. **Калькулятор с выбором класса авто (S / M / L / Другое):**
   - **S:** Седаны и хэтчбеки (Solaris, Camry, Octavia, Polo)
   - **M:** Кроссоверы и бизнес-класс (Tiguan, RAV4, BMW 5, Sportage)
   - **L:** Внедорожники и минивэны (Land Cruiser, X5/X7, Carnival)
   - **Другое / Микроавтобус:** Персональная оценка по фото
2. **Интерактивная SVG-карта зон автомобиля (вид сверху в разрезе):**
   - Мгновенная плавная подсветка выбранных зон (салон/сиденья, потолок, багажник, кузов, фары/стёкла, моторный отсек).
   - Всплывающие советы мастера при наведении для повышения доверия и среднего чека.
3. **Каталог услуг в 4 удобных табах:**
   - Химчистка салона (комплексная, глубокая с разбором, локальная со счётчиком сидений, озонация, уход за кожей).
   - Кузов и полировка (лёгкая, восстановительная, полировка фар, мойка моторного отсека).
   - Защита и пакеты (антидождь, твёрдый воск, керамика 9H, предпродажная подготовка).
   - Оценка по фото (для нестандартных задач и сложных пятен).
4. **Умный расчёт:**
   - Переключатель «Обычное состояние» vs «Сильные загрязнения / Шерсть (+30%)».
   - Автоматическое дотягивание до минимального чека (применяется к сумме работ).
   - Выездной детейлинг / забор авто (+1 500 ₽ фиксированная доплата поверх работ).
   - Смешанные заказы: «от X ₽ + оценка по фото» (никогда не показывает 0 ₽).
5. **Корзина с защитой от ошибок:**
   - Кнопка Undo (отмена удаления позиции).
   - Сохранение черновика и корзины в `localStorage` (переживает перезагрузку).
6. **Оформление и загрузка фото:**
   - Маска телефона СНГ, выбор формата (в студии / выезд с адресом), предварительная дата и время.
   - Загрузка до 3 фото с серверной проверкой формата (magic bytes) и сжатием в WebP через `sharp`.
   - Защита от повторной отправки (`idempotencyKey`).
7. **Приватная страница трекинга `/order/[token]`:**
   - Криптографически случайный токен доступа (номер телефона посторонним недоступен).
   - Статус заявки («Новая», «Согласована», «Завершена», «Отменена»).
   - Согласованное время поста и итоговая цена.
   - Быстрые кнопки связи с мастером (Telegram / WhatsApp / Звонок).
8. **2D Мини-игра на Canvas:**
   - «Отмой грязное стекло пальцем» — стирание слоя дорожного налёта с прогрессом в %.
   - Выдача персонального промокода на подарок или скидку при достижении 75% чистоты.

---

### Для владельца студии (`/admin`):
1. **Заявки:**
   - Поиск по имени, номеру телефона, марке авто и номеру заявки.
   - Фильтры по статусам.
   - Назначение согласованной итоговой цены и времени заезда (обязательны для перевода в статус «Согласована»).
   - Приватная заметка мастера (никогда не отдаётся клиенту!).
   - Просмотр фото и удаление заказа вместе с файлами.
2. **Тарифы:**
   - Редактирование базовых цен для классов S / M / L.
   - Настройка минимального чека, процента за сильные загрязнения и стоимости выезда.
3. **Студия (White-Label):**
   - Название, короткое имя, слоган, город, адрес бокса, телефон, Telegram, WhatsApp, часы работы.
4. **Игра:**
   - 3 режима: «Выключена», «Игра без награды», «Бонус на следующий визит» (с настройкой префикса, дней действия и суммы).
5. **Подсказки:**
   - Включение/отключение экспертных подсказок мастера на SVG-карте.
6. **Безопасность:**
   - Смена мастер-пароля с автоматическим аннулированием всех активных сессий.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Инициализация базы данных и сид
```bash
npx prisma db push
node scripts/seed.mjs
```

### 3. Запуск dev-сервера
```bash
npm run dev
```
Сайт доступен по адресу: `http://localhost:3000`  
Кабинет владельца: `http://localhost:3000/admin`  
Пароль по умолчанию: **`admin12345`**

## 📋 Чек-лист: как адаптировать шаблон под нового покупателя за 5 минут

Когда вы продаёте этот сайт детейлинг-студии или частному мастеру:

1. **Шаг 1. Базовые данные студии (1 минута):**
   - Откройте `src/config/brand.config.ts`.
   - Замените `studioName`, `city`, `address`, `phone`, ссылки на `telegramUrl` и `whatsappUrl`.
   - *(Или просто запустите сайт, зайдите в `/admin/studio` и сохраните новые данные через форму без открытия кода).*

2. **Шаг 2. Цены и тарифы (2 минуты):**
   - Перейдите в `/admin/tariffs`.
   - Введите реальный прайс студии для классов S, M, L.
   - Задайте порог минимального заказа (например, 2 500 ₽) и стоимость выезда мастера.

3. **Шаг 3. Мини-игра и бонусы (1 минута):**
   - Перейдите в `/admin/game`.
   - Выберите подарок за прохождение игры (например, «Озонация салона в подарок» или «Скидка 10%»).

4. **Шаг 4. Смена пароля администратора (30 секунд):**
   - Перейдите в `/admin/security`.
   - Задайте постоянный пароль владельца студии.

5. **Шаг 5. Передача проекта:**
   - Проект полностью автономен, не требует платных API-ключей, подписок и сторонних серверов.
   - Для деплоя на хостинг: залейте на Vercel, Timeweb Cloud, Amvera или VPS с Node.js 18+.

## 🔒 Безопасность и архитектурные гарантии
- **Серверный пересчёт:** Клиентскому расчету сервер не доверяет. Каждая заявка валидируется и пересчитывается по тарифам из базы на бэкенде.
- **Слепок цен (Snapshot):** В момент заказа в БД сохраняется JSON-слепок тарифов, поэтому будущие изменения прайса не изменят суммы в старых заказах.
- **Защита фото:** Файлы проверяются по Magic Bytes (только валидные JPEG, PNG, WebP) и сжимаются через `sharp`. Доступ к фото закрыт и отдается только по сессии администратора или совпадению секретного токена заявки.
- **Приватность:** Поле `privateStudioNote` полностью изолировано на сервере и не включается в клиентские ответы API.
